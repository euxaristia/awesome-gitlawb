# Contributing

Thanks for helping curate Awesome Twigpine.

## What belongs here

Anything built with or for the [Twigpine](https://twigpine.com) network:

- Nodes, clients, and CLIs
- Git transport helpers and libraries
- Agents and agent integrations (MCP servers, tools)
- Desktop, mobile, and web apps
- Guides, tutorials, and reference material

## Guidelines

- One entry per line, in the format: `**[Name](url)** — Short description ending with a period.`
- Put new entries in the most fitting section. Keep sections alphabetical where they already are.
- Describe what it does, not how great it is. No marketing language.
- Prefer projects that are usable today. Note the language or platform when it helps.
- Check that links resolve and the project is real before submitting.

## How to submit

1. Fork this repo.
2. Add your entry.
3. Open a pull request with a one-line summary of what you added and why it fits.

Entries that are broken, abandoned, or off-topic may be removed to keep the list useful.
